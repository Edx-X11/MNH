# MNH

MNH is a Discord bot and web app built by etworks.xyz.

## About

MNH uses Discord authentication for account handling and is designed to collect only minimal server usage data needed to provide and maintain the service. The project includes a privacy policy written for UK GDPR and Data Protection Act 2018 considerations.

## Features

- Discord authentication.
- Account handling through Discord.
- Minimal data collection.
- Server usage logging for performance, security, and debugging.
- Web app interface with a custom red-and-regal privacy policy theme.
